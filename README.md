## Тестовые функции

Лабораторные №2–7 используют один и тот же набор — это позволяет сравнивать методы между собой:

| Функция | Формула | Минимум |
|---------|---------|---------|
| f₁ (квадратичная) | 10x² − 4xy + 7y² − 4√5·(5x − y) − 16 | (√5; 0), f = −66 |
| f₂ (Розенброк, α = 1) | (x² − y)² + (x − 1)² | (1; 1), f = 0 |
| f₃ (Розенброк, α = 15) | 15·(x² − y)² + (x − 1)² | (1; 1), f = 0 |

Параметры экспериментов: начальные точки **[5, −2]** и **[−5, 10]**, точность ε = 10⁻² и 10⁻⁵ (в работе №1: 10⁻², 10⁻⁸, 10⁻¹⁷).

## Что внутри каждой работы

**№1. Метод дихотомии.** Минимизация функции с арксинусом и степенью ln 10 на отрезке [−1, 0]; сравнение числа итераций и вычислений функции при трёх значениях точности.

**№2. Градиентные методы.** Наискорейший спуск, где шаг выбирается одномерной минимизацией (золотое сечение), и спуск с дроблением шага (параметры `gamma`, `omega`, `xi`). Сравнение по числу итераций и вычислений функции для f₁–f₃. Основные функции: `gradient_descent`, `gradient_step_descent`.

**№3. Сопряжённые направления.** Метод сопряжённых градиентов с формулами Флетчера–Ривса и Полака–Рибьера; на квадратичной функции f₁ метод сходится за 2 итерации.

**№4. Метод Ньютона.** Классический и модифицированный (регуляризованный гессиан) методы Ньютона, аналитические градиенты и гессианы `hessian_f1/2/3`. Основные функции: `newton_method`, `newton_mod_method`, `regularized_inverse`.

**№5. Квазиньютоновские методы.** Аппроксимация обратного гессиана без его вычисления: DFP, BFGS и метод Пауэлла (`kvazinewton_methods`, `update_matrix`).

**№6. Методы нулевого порядка.** Методы, не использующие производных: циклический покоординатный спуск (`cps`), Хук–Дживс (`hook_jivs`), Розенброк (`rozenbok`); одномерный поиск — золотое сечение (`golden_ratio`). Есть визуализация траекторий на линиях уровня (`visualize`).

**№7. Симплексные методы.** Регулярный (`regsimp`) и нерегулярный (`irregsimp`) симплекс; визуализация эволюции симплекса на плоскости.

**№8. Условная оптимизация.** Минимизация на двух допустимых областях:
- Ω₁ — треугольник (три линейных ограничения);
- Ω₂ — эллипс (x+3)²/8 + (y+4)²/81 ≤ 1.

Реализованы метод **внутренних** (барьерных) штрафных функций (`InnerPenaltyMethod`) и **внешних** (`OuterPenaltyMethod`); на каждой итерации внутренняя задача решается методом Ньютона (`NewtonMethod`) с численными градиентом и гессианом (`NumericalAntigrad`, `NumericalHesse`). Стоимость оценивается как `2·grad + 4·hesse + f_calls`.

## Известные ограничения

- Код общих функций (f₁–f₃, градиенты) дублируется между ноутбуками — каждая работа самодостаточна, но общего модуля нет.
